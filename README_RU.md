# MCAi: начало русской локализации

Ветка разработки: `feat/russian-commands`. Это первая итерация; полный перевод сообщений задач ещё не выполнен.

## Что изменено
- Основные кнопки и справка чата используют языковые ресурсы Minecraft. Выберите русский язык в игре.
- В чате спутника: `стой`, `за мной`, `ко мне`, `отмена`, `статус`, `авто`, `экипировка`, `здоровье`, `помощь`.
- В обычном чате используйте префикс `!`: `!ко мне`, `!статус`.
- Точные команды добычи в чате спутника: `накопай земли 4 блока`, `собери 2 песка`.
- Поддержаны земля, песок, булыжник, гравий, глина; количество 1–128. Неизвестный ресурс или составная команда добычи вызывает уточнение, без подмены ресурса.
- Исправлен параметр количества английского локального обработчика: `maxBlocks` вместо `count`.

Количество передаётся существующему GatherBlocksTool: он учитывает уже имеющиеся ресурсы. Это целевое количество, а не обещание добыть столько дополнительных блоков. Поведение подбора, пути и результата задачи в этой итерации не переписано.

## Проверка
GitHub Actions выполняет автономные проверки разбора команд, затем собирает мод на Java 21. JAR доступен в артефакте MCAi-RU при успешной сборке.

Локально (Java 21): `gradlew.bat build`. Для Ollama сохраните текущий `model = "qwen3.5:9b"` в конфигурации.

Перед заменой JAR закройте игру, сохраните старый JAR и резервную копию тестового мира. В папке mods должна остаться только одна версия MCAi.

В игре проверьте русские кнопки, `стой`, `ко мне`, `отмена`, сбор 4 блоков земли при пустом инвентаре, отказ на неизвестный ресурс и количество 129. Полный запуск Minecraft/ATM10 здесь не проводился.
