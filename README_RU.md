# MCAi-RU 0.1.2 — понимание команд и подтверждение

Ветка `feat/russian-commands`, PR №1. Java 21, NeoForge 1.21.1.

В чате спутника:
- `накопай земли 4 блока` (также `на копай`)
- `добудь 4 угля`, `добудь 8 железа`, `собери 3 алмаза`
- `наруби 8 древесины`, `собери 4 дубовых бревна`
- `добудь уголь` → запрос количества → `4`
- `еще 4`, `столько же`, `повтори` используют последнее подтверждённое намерение. Контекст действует 10 минут.

Ollama разбирает русскую фразу в JSON без вызова инструментов. Мод проверяет действие, ресурс и количество, затем показывает предложение. `да` запускает его, `нет` отменяет. Предложение истекает через 2 минуты; новый запрос заменяет его. `стой`, `отмена`, `статус` работают сразу. Команды с `!` выполняются напрямую. Новое сообщение не отменяет действующее задание. Для нового задания сначала дождитесь результата или отмените текущее.

При ошибке Ollama/JSON действие не запускается. Произвольные команды сервера, стройка и крафт через этот канал не разрешены. Факты инвентаря и состояния передаются модели; старая переписка с выдуманными действиями не передаётся. Модель не дообучалась: адаптация выполнена через протокол, контекст и проверку намерений. `!статус` сохраняет последний результат или причину сбоя задания.

Поддерживаются земля, песок, гравий, глина, булыжник, камень, уголь, железо, медь, золото, алмазы, изумруды, лазурит, редстоун, кварц, древесина, дуб, берёза и ель. Количество 1–128, цифрами. Неизвестные ресурсы и составные запросы требуют уточнения.

Количество означает число новых добываемых блоков. Выпадение предметов зависит от блока и инструмента: например, камень без шёлкового касания даёт булыжник, одна руда может дать несколько предметов. Добыча ищет ресурсы поблизости; это не обещание найти отсутствующую руду во всём мире.

Управление: `стой`, `за мной`, `ко мне`, `отмена`, `статус`. В обычном чате — с `!`.

Основные ответы управления и добычи переведены, внутренние JSON/инструкции локальных команд убраны из чата. Модели задан русский язык ответов. Прочие механики оригинального мода могут ещё содержать английские сообщения.

Сборка: `gradlew.bat build`. GitHub Actions проверяет разбор команд и собирает JAR. Для установки можно повторить команду PowerShell из чата после закрытия игры. Ollama и модель в конфигурации сохраняются.

Игровые проверки: добыча при уже имеющихся ресурсах, продолжение «ещё», отмена, недоступный путь, неподходящая кирка, частичный результат. Автоматическая сборка не заменяет проверку в ATM10.
